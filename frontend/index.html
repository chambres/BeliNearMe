Beli Metadata Explorer

This UI starts with a Katy area search, but the form is fully generic. It uses Beli's recommendation endpoint instead of plain text search, so cuisine filters behave like metadata and not just a name match.

Results are ordered by the restaurant's average Beli score. The Rec Score is shown separately as a recommendation signal, because those are different metrics.
